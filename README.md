
# Text to Speech Converter

A clean and intuitive web application that converts written text into spoken words using the Web Speech API. 

## 🚀 Tech Stack

*   **HTML5** - Semantic structure and layout.
*   **CSS3** - Modern, responsive styling and animations.
*   **JavaScript (ES6+)** - Interactivity and integration with the Web Speech Synthesis API.

## ✨ Features

*   **Instant Conversion:** Convert text to audio in real-time.
*   **Voice Selection:** Choose from multiple voices available on the user's system.
*   **Controls:** Adjustable rate (speed) and pitch sliders.
*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewports.
*   **Control States:** Clean Play, Pause, and Stop functionality.

## 🛠️ Installation & Setup

No installation or build process is required. You can run this project locally in seconds.

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd text-to-speech
   ```
3. Open the `index.html` file in any modern web browser.
